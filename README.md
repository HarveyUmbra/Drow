# Die Defenierung des Games?

Eigentlich habe ich keine Ahnung was ich machen soll!!!
Momentan wird es ein Rollenspiel mit einer Top Down Perspektive.
Spielmechanich ist es von Klassischen Pen and Paper Rollenspielen insperiert.
Statt wie die alten klassiker sich von Action lasstigen Rollenspielen (DnD) zu Orentieren.
Sind meine Insperation er Sociale Rollenspiele (Power of Acolypse Rollenspiele, WoD).

Das Setting ist eine Universität, der Hauptgrund ist um mehr erzahlischere Freiheiten zu haben.
Das Studium ist eine Soziale Umwelsung des Leben eines Jungen Menschen.
Die Umgebung ändert sich.
